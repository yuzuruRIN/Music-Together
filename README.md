# 🎧 Music Together

ฟังเพลงด้วยกันแบบเรียลไทม์ — สร้างปาร์ตี้ แชร์โค้ดหรือลิงก์ แล้วทุกคนได้ยินเพลงเดียวกัน ตรงกัน

## ใช้งาน

- กรอกชื่อ (guest) → **สร้างปาร์ตี้** หรือ **ใส่โค้ด** เพื่อเข้าร่วม
- ค้นหาเพลง หรือวางลิงก์ YouTube / YouTube Music / **เพลย์ลิสต์สาธารณะ** ลงในช่องเดียวกัน
- ทุกคนเพิ่มเพลง จัดลำดับคิว เล่น/หยุด และกรอเวลาได้อิสระ
- **ข้ามเพลง** และ **ลบเพลงออกจากคิว** ต้องโหวต — เห็นด้วยเกินครึ่งของคนในห้อง (ถ้าอยู่คนเดียวผ่านทันที) โหวตหมดอายุใน 45 วินาที
- กด **ชวนเพื่อน** เพื่อแชร์ลิงก์ `/join/โค้ด` ให้เพื่อนเข้ามาโดยไม่ต้องกรอกโค้ด

## ติดตั้งและรัน

ต้องมี Node.js 22.9+ และ [yt-dlp](https://github.com/yt-dlp/yt-dlp) (ใช้ค้นหา/อ่านเพลย์ลิสต์/ดึงเสียง — ไม่ต้องใช้ API key)

```bash
npm install
pip install "yt-dlp[default]"      # หรือวางไว้ใน .venv/ หรือกำหนด YTDLP_PATH=/path/to/yt-dlp
npm run build
npm start                           # เปิด http://localhost:3001
```

พัฒนา: `npm run dev` (หน้าเว็บที่ :5173, เซิร์ฟเวอร์ที่ :3001)
ทดลองโดยไม่ต่อ YouTube: `npm run dev:mock` / `npm run start:mock` (ใช้เสียงโน้ตสั้นๆ แทนเพลงจริง)

### YouTube ขอยืนยันตัวตน ("Sign in to confirm you're not a bot")

YouTube บางครั้งบล็อก yt-dlp ที่ไม่ได้ล็อกอิน ลองตามลำดับ:

1. อัปเดต yt-dlp ให้ล่าสุด: `pip install -U "yt-dlp[default]"` (เวอร์ชันเก่าโดนบล็อกบ่อย)
2. แนบ cookies: คัดลอก `.env.example` เป็น `.env` แล้วตั้ง `YTDLP_COOKIES` (ไฟล์ cookies.txt) หรือ `YTDLP_COOKIES_FROM_BROWSER=firefox` จากนั้นรีสตาร์ท `npm start`

⚠️ cookies คือสิทธิ์เข้าบัญชี Google — ห้าม commit/แชร์ (`.env` และ `cookies*.txt` ถูก ignore ไว้แล้ว) และการใช้บัญชีหลักกับ yt-dlp มีความเสี่ยงที่ YouTube จะจำกัดบัญชี แนะนำให้ใช้บัญชี Google สำรองที่ล็อกอิน YouTube ไว้ในเบราว์เซอร์สำหรับ export เท่านั้น

### ให้เพื่อนเข้ามาจากเครื่องอื่น

- **วง LAN เดียวกัน:** เปิด `http://<IP เครื่องคุณ>:3001`
- **ต่างที่กัน:** ใช้ tunnel เช่น `cloudflared tunnel --url http://localhost:3001` หรือ deploy ด้วย `Dockerfile` ที่ให้มา (Railway / Render / Fly.io) — ต้องเป็นโฮสต์ที่รัน WebSocket ค้างได้

## ฟังตอนปิดหน้าจอได้อย่างไร

เสียงเล่นผ่าน `<audio>` ธรรมดา (ไม่ใช่ iframe ของ YouTube ซึ่งจะหยุดทันทีที่ปิดจอ) โดยเซิร์ฟเวอร์ดึงเสียงของวิดีโอมาเก็บไว้ชั่วคราว (`cache/`, ลบอัตโนมัติ) แล้วส่งให้ทุกเครื่อง
พร้อมตั้งค่า Media Session ให้ควบคุมจาก lock screen/หูฟังได้ และเมื่อเพลงจบเครื่องจะเริ่มเพลงถัดไปทันทีโดยไม่รอเซิร์ฟเวอร์ เพื่อให้เล่นต่อเนื่องแม้ปิดจอ

ข้อควรรู้: บนมือถือ ครั้งแรกที่เข้าห้องต้องมีการแตะ 1 ครั้ง (ปุ่มสร้าง/เข้าร่วม หรือ "แตะเพื่อเริ่มฟังเสียง") เบราว์เซอร์ถึงจะยอมเล่นเสียง

## โครงสร้าง

```
server/   index.js (HTTP + Socket.IO) · rooms.js (สถานะปาร์ตี้ คิว โหวต) · youtube.js (yt-dlp) · mock.js
client/   React + Vite — src/components, src/lib (useSyncedAudio = ตัวซิงก์เสียง)
```

หลักการซิงก์: เซิร์ฟเวอร์เก็บ `{เพลง, เล่น/หยุด, ตำแหน่ง, เวลาที่อัปเดต}` ทุกเครื่องคำนวณตำแหน่งปัจจุบันจากนาฬิกา server (วัด offset ตอนเชื่อมต่อ) และ seek แก้เมื่อเพี้ยนเกิน ~0.8 วินาที

## หมายเหตุ

การดึงเสียงจาก YouTube ผ่าน yt-dlp อยู่นอกเงื่อนไขการใช้งานของ YouTube เหมาะกับใช้ส่วนตัวกับเพื่อนในวงเล็กๆ ไม่ควรเปิดให้บริการสาธารณะ
